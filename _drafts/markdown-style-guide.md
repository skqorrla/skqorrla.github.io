## 제목 2단계 (## )

보통 단락입니다. 16px, 행간 1.8, 자간 −0.9%. 단락 사이 간격은 10px이고 긴 문장은 `word-break: break-all`로 줄바꿈됩니다. **굵게** 표시는 700이고, [링크](https://oliveyoung.tech)는 글자색을 유지한 채 보라색 1px 밑줄만 깔립니다. `인라인 코드`는 보라 글자에 연회색 배경입니다.

두 번째 단락입니다. 이 글은 `_drafts/`에 있어서 `--drafts` 옵션으로 serve 할 때만 보이고, 배포에는 포함되지 않습니다.

### 제목 3단계 (### )

목차에서 2단계(회색, 들여쓰기)로 들어갑니다.

##### 제목 5단계 (##### )

4·5단계는 목차에 들어가지 않고 17px 굵은 글자로만 보입니다.

> 인용문입니다. 왼쪽에 4px 회색 선이 있고 글자는 회색입니다.
> 두 줄 이상도 됩니다.

- 불릿 목록 첫 항목 — 6px 회색 점
- 불릿 목록 둘째 항목
  - 들여쓴 항목

1. 숫자 목록 첫 항목
2. 숫자 목록 둘째 항목

```python
def hello(name: str) -> str:
    """코드블록: 연회색 배경, 1px 테두리, 13px 모노스페이스"""
    return f"hello, {name}"
```
